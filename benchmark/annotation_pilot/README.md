# SNGS-137 战术标注 Pilot

填写 `annotation_template_SNGS137.csv`：`id` 已给出，只填写 `tactics`、`时间范围`、`判断依据`。

1. `tactics` 只能从 `annotation_vocabulary.csv` 的 P0/P1「中文名」原样复制；未达到任何战术门槛时填 `无明确战术`。
2. 时间写成 `00:01–00:12`（中间使用 `–`）；`无明确战术` 写 `00:00–00:30`。
3. `判断依据` 用一句话描述画面中可见的球员、球和防线动作，并说明为何符合该战术；不要参考模型输出、旧标签或文件名猜测。
4. 一个视频有多个战术时，复制该 `id` 新增多行，每行只写一个战术；正例和 `无明确战术` 不能同时出现。
5. 一次性完成模板内全部 137 个 `id`，不设置 20 条校准或中途复核；交付前检查每个 `id` 至少出现一次，最终 CSV 使用 UTF-8 编码。

本 CSV 只用于快速 pilot 与正例提名，不作为正式 QA GT；正式 GT 按 `docs/specs/2026-08-06-soccernet-tactics-annotation-spec.md` 填写 18 项 checklist。
